NetMonitor - GeoIP database (optional)
======================================

NetMonitor can show the country of each remote IP address. For that it needs a
free offline database file (MMDB format). Without it the program works normally;
the "Country" column just shows "-" for external addresses.

1. Download "IP to Country Lite" (MMDB format) from:
   https://db-ip.com/db/download/ip-to-country-lite
2. Extract the .mmdb file from the downloaded .gz archive (7-Zip works).
3. Put the .mmdb file in THIS folder (next to NetMonitor.exe), then restart NetMonitor.

The lookup is done locally; no IP address is sent anywhere for this feature.

NetMonitor - GeoIP veritabani (istege bagli)
============================================

Uzak IP adreslerinin ulkesini gostermek icin ucretsiz bir cevrimdisi veritabani
dosyasi (MMDB bicimi) gerekir. Dosya olmadan da program calisir; "Country"
sutununda dis adresler icin "-" gorunur.

1. https://db-ip.com/db/download/ip-to-country-lite adresinden "IP to Country Lite"
   veritabanini MMDB bicimiyle indirin.
2. Indirilen .gz arsivinden .mmdb dosyasini cikarin (7-Zip ile).
3. .mmdb dosyasini BU klasore (NetMonitor.exe'nin yanina) koyun ve NetMonitor'u yeniden baslatin.
